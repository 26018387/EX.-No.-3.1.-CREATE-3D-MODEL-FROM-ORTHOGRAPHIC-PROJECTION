# EX. No.3.1. CREATE 3D MODEL FROM ORTHOGRAPHIC PROJECTION
## DATE:

## AIM:
To create a 3D model from given orthographic projection.

## REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:
1.	Open new file and then select sketch icon.
2.	Select the plane for sketching. 
3.	Use sketching features (line, circle, arc, rectangle, polygon, etc.,) to draw the given sketch.

<img width="587" height="1280" alt="image" src="https://github.com/user-attachments/assets/32f8b59a-0d27-492f-9b2e-e25580401785" />


4.	Use sketch modifying features (cut, trim, mirror, move, etc.,) to edit the sketch.

<img width="587" height="1280" alt="image" src="https://github.com/user-attachments/assets/33cadd1e-ea5a-4051-a0df-95ae8f66b1a8" />


5.	Use inspect feature to measure the dimensions of sketch.
<img width="1158" height="883" alt="image" src="https://github.com/user-attachments/assets/21fa306f-08a4-4209-9a6f-2b912827080c" />



6.	After finishing the sketch use finish sketch option to finalize the sketch.
<img width="684" height="1279" alt="image" src="https://github.com/user-attachments/assets/774d8563-5e8c-4909-b21a-66da201fd6e2" />



7.	Use extrude option to convert 3D model from sketch
